# PptInk v0.9.6 设置中心与交互体验增强说明

## 本轮新增与调整

### 画笔设置

- 新增独立「画笔」分页，可从 8 种常用颜色中选择默认画笔颜色，也支持 `#RRGGBB` 自定义颜色。
- 新增默认画笔粗细设置（0.6–6.0 mm），修改后同步到当前使用的笔和工具栏调色面板。
- 为荧光笔增加常用颜色预设及自定义 HEX 颜色。
- 增加「恢复默认画笔」，一次恢复默认画笔色、线宽和荧光笔颜色。
- 自定义颜色输入实时更新颜色预览；应用后刷新当前页，避免选中态或控件值陈旧。
- 墨迹层状态牌开关会立即请求舞台重绘，无需等下一笔输入或其他诊断帧触发刷新。

### 工具栏可见性

- 闲置淡化默认关闭，不再让主工具栏在用户不操作时无提示地变淡。
- 如用户主动开启，可自定义等待时间（UI 提供 0.5–15 秒）和闲置后的不透明度（20%–100%）。
- 等待时间、透明度和开关独立持久化；运行中的工具栏立即应用新值，不必重启程序。

### 动效与触摸布局

- 新增「减少界面动效」选项。启用后，视图切换、淡入淡出、弹层缩放和吸附位置等动画直接到达终态；动画完成回调仍执行，避免关闭/卸载逻辑因动画等待而滞留。
- 设置窗按当前放映屏尺寸约束大小，内容区域支持垂直触摸滚动。
- 导航、分段选项、自绘开关、主要操作按钮和滑杆增大触控目标，控制说明文本换行受约束，降低窄窗口下挤压控件的概率。开关行整个区域均可触摸切换，不必精确点中右侧小开关。
- 滑杆拖动时实时更新运行状态，但把配置落盘合并到短暂停手后；设置窗口关闭时会补存最后一次值，减少每次触摸报点都进行磁盘 I/O 的抖动风险。
- AI 形状识别等待时间可在设置中调整（150–5000 ms），并即时保存。
- 输入设置中将「行为」页更名为「行为与触控」，把减少动效、触控误触与识别节奏放在更一致的设置分区中。

### 配置和打包一致性

- `AppConfig.Normalize` 对新增等待秒数和不透明度做范围钳制，防止旧版或手动编辑的异常配置破坏 UI。
- 修正 `DefaultEraseMode` 对 `clear` 值的归一化白名单，避免界面提供选项但保存后被悄悄改回。
- 修正 CI 上传的便携包 artifact 名称与 v0.9.6 打包脚本输出名不一致的问题。
- 更新 README 版本号和构建边界说明，避免把历史构建结果误当成本轮最新源码已编译的证明。

## 验证

- Python 回归：使用项目现有测试集执行 `python -m pytest python/tests -q`。
- XML/XAML：对项目 XAML、WPF 项目文件及 CI YAML 进行结构解析/静态检查。
- C#：执行源码括号/定界符检查和设置字段引用扫描。
- 本运行环境没有 `dotnet`、MSBuild 或 C# 编译器，因而不声称本轮 WPF 程序通过了编译。请用 Windows CI 的 Release 构建验证语义、引用和资源是否完整，再在目标触摸设备验收实际手感。

## 推荐的实机验收路径

1. 先关闭闲置淡化，验证工具栏持续清晰；再开启淡化并调整等待时间/透明度，确认任意触摸、笔或鼠标操作立即恢复。
2. 依次选择画笔预设、应用自定义 HEX 颜色、改变线宽并点「恢复默认画笔」，检查当前画笔与工具栏调色面板显示同步。
3. 开启「减少界面动效」，连续切换设置分页、展开和收回工具栏面板，确认状态立即到位、没有回调遗漏。
4. 调整 AI 识别等待时间后绘制直线、圆形与连续手绘，确认延迟和自动/气泡模式各自符合设置值。
5. 在低分辨率与高 DPI 放映屏上滚动设置页，检查开关、颜色和按钮可完整点按且没有超出窗口。
