# 版本历史

## v1.1.0

面向真实课堂的一轮大整改（Hydrotessera）：修掉一批会丢板书、卡死、失灵的缺陷，
补齐发布链路，统一版本号。构建 0 警告 0 错误，识别与协议测试 39 项全部通过。

### 板书数据安全（重点）

- **整笔抹除 / 圈除撤销假成功**：命中笔在移除瞬间没记索引，抬笔才构造撤销指令——
  届时笔已不在页面上，撤销返回成功却什么都不恢复，板书永久丢失。改为移除瞬间捕获，
  撤销按原位置与原层级整批复原；同一手势反复擦过同一区域不再复活中间段。
- **换课件批注串页**：墨迹文档全程单例、按页码缓存且从不清理——同一节课换一份课件，
  旧课件的批注会原样盖在新课件相同页码上。现在按演示文稿身份检测换课件：旧会话自动
  存档后清空，同课件重开放映不受影响。
- **书写中切工具的竞态**：工具切换入口没持引擎锁，与墨迹线程并发轻则崩进程、重则
  撤销树损坏（已擦的笔不入历史，无法撤销）。锁序收敛后该窗口闭合。
- **久压不抬笔画死程序**：单笔超过 8192 个报点触发点数折半后，收笔补点循环永不
  终止并抱死引擎锁，整个书写功能冻结只能杀进程。折半现在与平滑流同步。
- **滑动清空误触发**：时间单位换算错了一万倍，慢速划过四分之一屏就被当成"快而长"
  的手势整页清空。文档承诺的"慢速涂画不触发"现在是真的。

### 输入与手感

- 手掌搭在工具栏/翻页岛上书写时，被屏蔽的触点无限期占住输入单槽，真正书写的手指
  被静默吞掉——现在被屏蔽触点不占槽，且会为新书写让位。
- 擦除/清空手势进行中翻页，半截手势会落到新页上把新页板书擦掉——翻页即作废当前手势。
- 未放映时在设置里切输入档位会唤起一块全屏隐形窗口吞掉所有输入——隐藏状态下不再
  自行显示舞台。
- 抬笔收锋的位置系统性偏移 1~2 点（渲染缓存落后于最终点数），笔尖收锋形状失真。

### 放映检测与翻页

- **S2 避让失效**：切到希沃白板后 500ms 无条件弹回，置顶墨迹层盖住白板截胡书写。
  现在恢复前先确认外来覆盖已离开前台。
- **PPT 假死时看门狗自锁**：判死流程先做的 COM 探测正好挂死在假死的 PPT 上，
  回收机制在它为之设计的场景下失灵。探测顺序与超时护栏重排后，两种假死形态都能回收。
- 重启放映检测不到：开场抖动吞噬后检测状态滞留，此后重开的放映整场无批注。
- COM 事件订阅失败时连接点每 5 秒泄漏一个，一节课累积数百个重复回调。
- 翻页笔方向键不再吞设置窗口的文本框输入。
- 放映窗口丢失时兜底按键不再发给前台任意窗口（原先会把翻页键发给浏览器）。

### AI 与插件

- 「最近几笔」识别只替换最后一笔，前面几笔原迹叠在规整图形上出重影——多笔范围
  现在整批替换，一次撤销整批恢复。
- `recognizer_config.json` 从未被读取，用户按文件头注释调参全部静默失效。
- 开着 AI 的 25 秒内退出程序会卡在桥进程握手上，强杀还会丢板书快照——退出先存
  板书再收桥，握手可被退出打断。
- AI 自动配置的子进程超时后不再留孤儿 pip 与 Python 进程。
- **已装插件重启后消失**：安装只注册进当次进程，现在启动时扫描插件目录、按同一套
  规则校验后加载。
- 插件包解压按实际写入字节限制 20 MB（原先只看 zip 声明值，可被绕过）。
- network 权限没有任何对应能力，不再为它弹授权框；文档如实标注。

### 稳定性与工程

- 每写一笔就同步全量落盘配置（含强制刷盘）——改为同色短路 + 500ms 防抖合并写。
- 启动失败时异常与日志全不落盘（服务尚未建好时日志语句被空跳）——单例日志器兜底，
  后台线程与未观察任务的异常也记日志后再退出。
- 配置文件损坏不再静默回默认：坏文件备份为 `.bad-时间戳` 并记日志。
- 笔记本试用模式重启后手掌抑制复活——启动时按配置补齐。
- 托盘「隐藏图标（下次放映自动恢复）」从未恢复——放映唤起时兑现承诺。
- 截图插件在 UI 线程同步编码 4K PNG 卡住整个舞台——挪到后台线程并提示进度。
- 机型档案目录里一个坏 JSON 不再连坐其余档案全部失效。
- 扩展屏上手势区判定用错坐标系（没减屏幕原点），半块板拒绝起笔。
- 历史树上限在正常连续书写下永远不生效（无枝可剪）——线性历史重新定根，内存
  不再只增不减。
- 死代码清理：采样记录器（零引用）、Python v1 识别遗留块（约 250 行）、从未接线的
  位图擦除管线、废弃 P/Invoke。

### 发布与版本

- **仓库目录扁平化**：原先所有内容嵌套在版本号子目录里，GitHub 首页空白、CI 从未
  在默认分支跑过、按 README 构建必失败。现已拉平到仓库根，CI 恢复工作。
- 便携包脚本删除 5 个早已不存在的文档引用（打包必失败）；启动器补 `--portable`
  （不再给试用机留开机自启）；包内随附 LICENSE 与第三方声明（MoonSharp/MIT）。
- 版本号统一为 1.1.0，csproj 为单一来源（打包脚本、程序集版本、设置页"关于"、
  HTTP UA 自动跟随）；开发模式 `dotnet run` 也能找到 AI 桥脚本了。
- AI「仅手动识别」设置项此前没有任何触发点（选了也走自动），本轮修复后行为与文案一致。

## v1.0.0 stable

第一个稳定版。AI 识别全参数化、环境配置可见、新增高级模式精调笔墨。

### AI 识别

- **识别时机可配**：停顿后（默认，防连笔误识）/ 抬笔即识（最快，适合快速作图）/ 仅手动（只点【AI】才认）。
- **识别范围可配**：最后一笔（默认）/ 最近几笔（把最近两笔合起来认，应对"圆+箭头"这类组合图形）。
- **识别能力可配**：
  - 置信度阈值（低于此值不规整，越高越保守）；
  - 最小识别尺寸（太小的笔迹不认，避开小勾小点被误规整）；
  - 形状白名单（只认列出的形状，如 `circle;line;arrow`，用于禁掉课堂常误识的形状）；
  - 识别超时（超过就放弃本次，板书不卡）；
  - 成功提示开关。
- **环境配置可见**：点「快速检测 AI 功能」时按钮文案会实时显示进度
  （检测运行环境 → 环境不完整，自动配置中 → 下载运行时 → 复检中），
  不再是无反馈的长时间等待。

### 高级模式

设置中心新增「高级」页（需先在页内打开「高级模式」开关）：

- 平滑强度（越大越跟手 / 越小越稳）
- 笔锋幅度（0 = 等宽无笔锋）
- 起笔渐入长度、收笔收锋长度
- 宽度跟随（越大越活 / 越小越平滑）
- 压感强度
- 荧光笔笔尖横竖比（0.5 = 竖矩形横粗竖细；1.0 = 圆头等宽）
- 荧光笔透明度

一键「恢复默认笔墨参数」。所有参数走同一真源（`PenTuning` / `BuildWidths` / `DrawStroke`），
实时书写、抬笔精修、PNG/SVG 导出共用同一组值 —— 不会出现"屏幕一套、导出一套"。

### 稳定版收口

- 修 v0.9.9 引入的两处问题：会话隔离分支的宽度缓存 key 漂移（会覆盖收锋）、
  荧光笔导出与屏幕不一致（导出改走同一轮廓）。
- 版本号统一为 1.0.0。

## v0.9.9

笔迹和手感大改动，外加引导重写、翻页岛半透明、AI 自愈。

### 墨迹（重点）

- **快速连写丢笔**：`OnStylusDown` 原来不检查上一笔是否收尾，快速连写时新笔直接把
  `_live` 覆盖掉 —— 第一笔丢了，第二笔还被第一笔迟到的 Up 误提交。现在新笔落下前
  先把上一笔收尾提交，不丢笔、不串笔。这条是「连笔」和「粗细突然跳」的主因。
- **粗细跳变**：速度是「位移 ÷ 时间」，红外框报点抖动 ±1~2px 会被除法放大成两倍速度跳变，
  直接喂给宽度公式就是一会粗一会细。现在速度先过 EMA 低通，再加一道「相邻宽度变化 ≤12%」
  的硬截断，突变从机制上没了。
- **笔锋**：起笔渐入从 0.35/6 点加深到 0.20/8 点，收笔收锋从 0.25/8 点加深到 0.12/12 点，
  改用三次缓动。落笔和提笔的粗细变化肉眼可见。
- **跟手**：OneEuro 的 minCutoff 1.0→1.2、beta 0.020→0.045，快写滞后更小、转角不粘滞。

### 荧光笔（重点）

- **一条线深浅不一**：原来按描边分段画，每段是圆头笔帽，分段处两个圆头在半透明下
  两两叠加 —— 一条没画重叠的线也会「深~浅~深」。现在整条笔迹改用**填充多边形**渲染，
  单一填充、恒定透明度，伪影从机制上消失。
- **方向性笔尖**：真实荧光笔的笔尖是竖矩形，横画粗、竖画细。现在按每点运动方向计算
  垂直于轨迹的墨带宽度（横画 = 笔尖高、竖画 = 笔尖宽的一半），填充出真正的荧光笔形态。
  笔尖不随速度、压感变化，宽度恒定。

### 其他

- **翻页岛闲置半透明**：左右翻页岛现在和工具栏共用同一套闲置淡化设置（开关、等待时间、
  透明度都一致）。设置里改一处，三个元素一起变。
- **新手引导重写**：
  - 欢迎步三个选择：「来看看怎么使用」（强调色）/「我先上课」（本次跳过，下次还提示）/
    「我不想使用 PptInk「本次隐藏」」（取消勾选，今后不再自动提示）。
  - 文案全部重写为口语短句，去掉了套话和排比。
  - 样式简化：去掉大圆底徽标，改 22px 线性图标；卡片圆角 20、留白更足。
- **AI 环境自动配置**：新增 `AiProvisioner`。开启 AI 后若环境不可用，程序按序自愈 ——
  内置运行时补齐 NumPy → 退到系统 Python → 都缺就下载嵌入式 Python 并装 NumPy，
  直到一次真实识别通过为止。设置中心的「快速检测 AI 功能」失败时会自动触发这一流程并复检。

## v0.9.8

修用户反馈的 5 个问题。

- **引导高亮挖错位置**：讲「怎么收起工具栏」那一步，高亮原来挖在【笔】上，改成挖在拖动柄上。
  新增 `IOnboardingTargets.Grip()` 与 `Toolbar.GetGripPhysicalRect()`。
- **控件文字在浅色主题下看不见**：插件面板族的按钮文字和面板底色原来写死成深色底+暖白字。
  浅色主题下面板变浅底，文字还是白的，就成了白底白字。
  现在这些颜色全部走主题资源（`TextPrimaryBrush` / `ContentBackground`），跟主题一起切换。
  涉及 `PluginUiKit`、计时器、随机点名、板中板工具条、Lua 插件宿主面板。
- **滑块拖不动**：两个原因。一是自定义模板里轨道两侧的 RepeatButton 没设高度，
  命中区塌缩成一条零高度的线，点轨道点不中；二是 WPF 自带的 Thumb 拖动状态机在
  红外框上会「拖到一半丢手」。现在给 RepeatButton 设 44px 高，并新增 `TouchSliderKit`
  做触摸直驱：按下即定位、移动即跟随、松手即停，不再依赖 Thumb 状态机。
  Thumb 也放大到 32px。
- **文案去 AI 味**：引导 10 步、设置页全部描述、Toast 提示、副标题和 Tooltip 都重写了一遍，
  压短、去掉了排比和破折号，改成老师平时会说的话。
- **文档统一**：删掉 6 个分散的说明文档（还带着编码损坏的文件名），合成这一份 CHANGELOG；
  README 重写，去掉和实际情况矛盾的段落。

## v0.9.7

修用户反馈的 7 个问题。

- 引导补一步讲怎么收起工具栏。
- 工具栏显示和设置对不上：分割标记残留、副岛却是空的，导致撤销/重做/AI/插件既不显示也没法恢复。
  加了三层自愈（配置加载、主栏重建、副岛重建），设置页加了「合并副岛回主栏」。
- 笔的浮岛只显示红黄两色：原来用的是硬编码 5 色板。现在改成和设置中心同源
  （笔 8 色、荧光笔 5 色）+ 最近用色。
- AI 桥检测不到：桥脚本只认 `bridge\` 一个路径，换成多路径探测；握手超时 15s→25s，
  健康检查 18s→28s（嵌入式 Python 冷启动在低配机器上能到 20 秒出头）。
- 擦除卡顿：像素擦除改成只扫新增路径段 + 包围盒预筛；擦除判定限到 ~125Hz；
  擦除手势进行中不再重建 4K 整页缓存（这一条是掉帧的主因）。
- 滑块难用：加了触摸友好样式（大 Thumb、粗轨道、点轨即跳），关键项配 −/+ 微调按钮。
- 书写手感：滤波换成 OneEuro（慢写防抖、快写不滞后）；加了起笔渐入和收笔收锋；
  笔画从折线改成二次贝塞尔曲线。

另外这一版第一次在本环境跑通了真实编译：Linux 上用 `EnableWindowsTargeting`
就能编译 WPF 工程，并交叉产出 Windows x64 便携包。
