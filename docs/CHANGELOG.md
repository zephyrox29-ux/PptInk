# 版本历史

## v1.1.2（稳定可选 Beta AI）

本版在 v1.1.1 测试构建基础上收口放映页同步、COM/输入线程、手掌抑制、换课件数据安全，
并把 v1.0.0Beta 的多笔几何矫正/文字防误触/课后疑惑询问做成默认关闭的可选 AI 功能；
新增翻页笔音量/亮度媒体键翻页兜底。

- 放映开始、换课件、S2 恢复、手动唤起都会无条件把 InkEngine 当前页对齐到 session 页，
  修复“首页板书写进上一场旧页”的整场错页；页码轮询缓存跨会话复位。
- COM 主通道专用 STA 改为真正的 Dispatcher 消息泵；翻页/跳页/退出/身份读取改由
  PptController 的专用 STA 执行，UI 不再同步等待假死 PPT；COM 探活失败允许 WinEvent 接管。
- 通道 B 的 Down/Move/Up 批量报点逐点喂入、抬笔提交最后一点，修复尾段截断与批内时间戳相同；
  长笔画折半提前留余量，消除极端补点死循环。新增接触面积触控手掌守卫。
- 换课件自动导出关闭时先弹“导出旧板书”确认；便携模式设置页不能绕过 --portable 写自启；
  “显示托盘图标”不再只在静默启动生效。
- 新增“音量/亮度键翻页（翻页笔兜底）”：音量/媒体键由低级键盘钩子、HID Consumer Control
  亮度键由 Raw Input 映射为上一页/下一页（放映中有效，可关闭）。
- 引入 Beta AI 可选功能（默认关闭）：缝隙闭合、补笔接续、阴影对齐、文字/公式防误触、
  课后疑惑笔迹询问与白名单自优化；所有几何后处理在后台快照上运行，结果回 UI 走撤销栈。
- 修复 Plugin Studio 工程 Entry 任意路径写/读、导入→保存丢失 Resources、脚本/包体限制与
  主程序不一致；新增目录导入、示例库直接克隆、未保存修改提示。
- 设置高级笔墨参数改为防抖落盘并强制重合成已有板书；画笔浮岛拖 RGB 滑块不再每帧写盘
  （停手 400ms 落一次，关面板立即补落）；极简材质真正移除阴影；
  主题卡换行、页码浮层尺寸/触控目标、擦除浮岛滑块触摸直驱、减少动效覆盖核心 UI。
- AI Python 桥加固：缺 NumPy / 识别模块时子进程不再直接退出，改为保持可服务并在
  hello/ping 里回报依赖状态，C# 侧把"桥不可用"翻译成"缺 NumPy / 识别模块加载失败 /

## v1.1.1（测试构建）

真机验收前的收口版本（Hydrotessera）：集中修 UI 定位与缩放类缺陷（对应试用反馈里的
「浮窗乱跑、UI 错位」），根据首轮实测反馈修可用性问题，补真机排障取证能力，收紧两处
隐私与供应链默认值。构建 0 警告 0 错误；C# 新增测试项目 7 项、Python 识别与协议测试
40 项全部通过。**混合 DPI 双屏定位的修复开发机只能验一半，本版本按测试构建对待，
待真机验收。**

### 可用性（首轮实测反馈）

- **工具栏只剩几个基础工具、找不到撤销/AI/插件**：根源是「可分割副岛」特性——工具栏
  中部有一段 44px 的隐形分割缝，触摸滑动很容易误触发，把撤销/重做/AI/插件/结束放映
  切到副岛，而副岛在多数环境根本不可见（等于整组功能消失）。特性整体移除：工具栏
  恒定完整显示，旧配置里的分割标记自动清除。
- **轻点的墨点擦不掉**：涂抹擦除的命中循环从第二个点开始遍历——单点笔迹（轻点/误触
  留下的红点）永远不参与命中，怎么擦都在。现在点按点距判定，墨点可正常擦除。
- **插件/擦除/画笔面板点击没反应**：新手引导的模态租约在跳过/完成/强停时不归还，
  之后所有弹出面板被模态占用静默拒绝（提示也被吞掉）。退场路径全部配对归还租约。
- **桌面播新手引导后无法退出**：托盘「立即播放新手引导」会先唤起工具栏，引导播完后
  UI 留在桌面且没有退出按钮。现在桌面会话的引导结束即收回全部唤起 UI，回到托盘驻留。
- **亚克力材质异常**：本应用全部窗口都是 WPF 透明分层窗口，DWM 亚克力在其上不生效
  且实测渲染异常——「系统级实时模糊」是虚假承诺，选项移除（旧配置自动映射回半透明）。
- **设置面板拖不动、拖动鬼畜闪动**：标题栏 95% 的区域没有参与命中测试（只有恰好压在
  标题文字上才能拖）；修上命中后改用系统原生 DragMove 移动——逐帧写窗口坐标在透明
  分层窗口上会整窗重合成闪动，原生移动零重绘。
- **工具栏只能横着拖、底部悬空占地方**：纵向放开为全屏自由拖动（位置记忆保留）；
  底部手势区预留 64px 收窄为 48px（无手势区环境 16→8px），整体更贴底。
- **快捷跳页**：点按翻页岛的页码胶囊弹出页码网格，点选即 COM 直跳（开发机已连
  PowerPoint 实测）；无 COM 时明确提示。
- **浮窗收窄**：工具栏/翻页岛按钮 56 → 48px（仍满足触控目标下限），边距同步收紧。
- 教程与设置中的署名补全：Xianfish & Hydrotessera。

### 窗口定位与缩放

- **工具栏缩放尺寸口径**：缩放 0.7~1.6 生效后，停靠/拖动/钳制仍在用未缩放尺寸计算
  ——放大档视觉越出中央槽压到翻页岛、缩小档底边悬空、画笔面板向上展开又被拉回压住
  副岛行。全部位置计算统一为缩放后的视觉尺寸。
- **锚点矩形多除一次 DPI**：非 100% 缩放下擦除浮岛、插件面板、副岛合并手势的锚点
  中心随缩放漂移。换算只对原点除 DPI，尺寸不再重复缩放。
- **混合 DPI 跨屏定位**：WPF 的窗口 Left/Top 在不同缩放的两台显示器间落点是错的
  （WPF 已知缺陷），笔记本 + 大屏的组合下全屏舞台可能落到错误的屏、差一个缩放比。
  现在窗口按监视器物理像素钉位，内部元素坐标一律以放映屏监视器口径换算。
- **放映屏生命周期**：进放映第一帧前就刷新目标屏（原先要等最长 500ms 的页码轮询，
  首帧按旧屏出现再整个跳过去）；放映窗口短暂取不到时不再把整套 UI 拉回主屏反复跳屏；
  退出放映后托盘唤起的设置窗/提示回到主屏，不再出现在可能已关闭的投影屏上。
- **聚光灯**：暗罩在布局里尺寸为 0 从未显示过，点暗区退出也不命中——聚光灯此前只剩
  一个可拖的圆环。两处都修了。
- 「规整为」气泡的锚点用的是固定 3840×2160 墨迹模型坐标，1080p 视口下放大 2 倍，
  气泡恒被钳到屏幕右侧而不是笔迹上方。
- 「避让系统手势区」开关改完立即重排工具栏与翻页岛；放映中换屏时引导覆盖重渲染当前
  步骤的挖洞、设置窗跟移动屏、弹出型浮层换屏前先收回。

### 隐私与供应链默认值

- **退出/换课件不再自动把板书写到桌面**（默认关闭，设置里可开回）。共用教室电脑上，
  原行为等于默认把整节课板书留给任何后来者。换课件丢弃旧板书时会提醒先手动导出。
- **AI 运行时下载先确认再动手**：弹窗说明来源（python.org / PyPI）、体积与安装位置，
  拒绝则不联网、AI 不启用（书写不受影响）；嵌入式 Python 固定 URL + SHA256 与字节数
  双重校验，NumPy wheel 按 PyPI 元数据指纹校验；不再对系统 Python 执行 pip 安装，
  一切只写进程序目录。

## v1.1.0

面向真实课堂的一轮大整改（Hydrotessera）：修掉一批会丢板书、卡死、失灵的缺陷，
补齐发布链路，统一版本号。构建 0 警告 0 错误，识别与协议测试 39 项全部通过。

### 板书数据安全（重点）

- **整笔抹除 / 圈除撤销假成功**：命中笔在移除瞬间没记索引，抬笔才构造撤销指令——
  届时笔已不在页面上，撤销返回成功却什么都不恢复，板书永久丢失。改为移除瞬间捕获，
  撤销按原位置与原层级整批复原；同一手势反复擦过同一区域不再复活中间段。
- **换课件批注串页**：墨迹文档全程单例、按页码缓存且从不清理——同一节课换一份课件，
  旧课件的批注会原样盖在新课件相同页码上。现在按演示文稿身份检测换课件：旧会话自动
  存档后清空，同课件重开放映不受影响。
- **书写中切工具的竞态**：工具切换入口没持引擎锁，与墨迹线程并发轻则崩进程、重则
  撤销树损坏（已擦的笔不入历史，无法撤销）。锁序收敛后该窗口闭合。
- **久压不抬笔画死程序**：单笔超过 8192 个报点触发点数折半后，收笔补点循环永不
  终止并抱死引擎锁，整个书写功能冻结只能杀进程。折半现在与平滑流同步。
- **滑动清空误触发**：时间单位换算错了一万倍，慢速划过四分之一屏就被当成"快而长"
  的手势整页清空。文档承诺的"慢速涂画不触发"现在是真的。

### 输入与手感

- 手掌搭在工具栏/翻页岛上书写时，被屏蔽的触点无限期占住输入单槽，真正书写的手指
  被静默吞掉——现在被屏蔽触点不占槽，且会为新书写让位。
- 擦除/清空手势进行中翻页，半截手势会落到新页上把新页板书擦掉——翻页即作废当前手势。
- 未放映时在设置里切输入档位会唤起一块全屏隐形窗口吞掉所有输入——隐藏状态下不再
  自行显示舞台。
- 抬笔收锋的位置系统性偏移 1~2 点（渲染缓存落后于最终点数），笔尖收锋形状失真。

### 放映检测与翻页

- **S2 避让失效**：切到希沃白板后 500ms 无条件弹回，置顶墨迹层盖住白板截胡书写。
  现在恢复前先确认外来覆盖已离开前台。
- **PPT 假死时看门狗自锁**：判死流程先做的 COM 探测正好挂死在假死的 PPT 上，
  回收机制在它为之设计的场景下失灵。探测顺序与超时护栏重排后，两种假死形态都能回收。
- 重启放映检测不到：开场抖动吞噬后检测状态滞留，此后重开的放映整场无批注。
- COM 事件订阅失败时连接点每 5 秒泄漏一个，一节课累积数百个重复回调。
- 翻页笔方向键不再吞设置窗口的文本框输入。
- 放映窗口丢失时兜底按键不再发给前台任意窗口（原先会把翻页键发给浏览器）。

### AI 与插件

## v1.0.0 stable

### AI 识别

- **识别时机可配**：停顿后（默认，防连笔误识）/ 抬笔即识（最快，适合快速作图）/ 仅手动（只点【AI】才认）。

  - 成功提示开关。
- **环境配置可见**：点「快速检测 AI 功能」时按钮文案会实时显示进度
  （检测运行环境 → 环境不完整，自动配置中 → 下载运行时 → 复检中），
  不再是无反馈的长时间等待。

### 高级模式

设置中心新增「高级」页（需先在页内打开「高级模式」开关）：

- 平滑强度（越大越跟手 / 越小越稳）
- 笔锋幅度（0 = 等宽无笔锋）
- 起笔渐入长度、收笔收锋长度
- 宽度跟随（越大越活 / 越小越平滑）
- 压感强度
- 荧光笔笔尖横竖比（0.5 = 竖矩形横粗竖细；1.0 = 圆头等宽）
- 荧光笔透明度

一键「恢复默认笔墨参数」。所有参数走同一真源（`PenTuning` / `BuildWidths` / `DrawStroke`），

## v0.9.9

笔迹和手感大改动，外加引导重写、翻页岛半透明、AI 自愈。

### 墨迹（重点）

- **快速连写丢笔**：`OnStylusDown` 原来不检查上一笔是否收尾，快速连写时新笔直接把
  `_live` 覆盖掉 —— 第一笔丢了，第二笔还被第一笔迟到的 Up 误提交。现在新笔落下前
  先把上一笔收尾提交，不丢笔、不串笔。这条是「连笔」和「粗细突然跳」的主因。
- **粗细跳变**：速度是「位移 ÷ 时间」，红外框报点抖动 ±1~2px 会被除法放大成两倍速度跳变，
  直接喂给宽度公式就是一会粗一会细。现在速度先过 EMA 低通，再加一道「相邻宽度变化 ≤12%」
  的硬截断，突变从机制上没了。
- **笔锋**：起笔渐入从 0.35/6 点加深到 0.20/8 点，收笔收锋从 0.25/8 点加深到 0.12/12 点，
  改用三次缓动。落笔和提笔的粗细变化肉眼可见。
- **跟手**：OneEuro 的 minCutoff 1.0→1.2、beta 0.020→0.045，快写滞后更小、转角不粘滞。

### 荧光笔（重点）

- **一条线深浅不一**：原来按描边分段画，每段是圆头笔帽，分段处两个圆头在半透明下
  两两叠加 —— 一条没画重叠的线也会「深~浅~深」。现在整条笔迹改用**填充多边形**渲染，
  单一填充、恒定透明度，伪影从机制上消失。
- **方向性笔尖**：真实荧光笔的笔尖是竖矩形，横画粗、竖画细。现在按每点运动方向计算
  垂直于轨迹的墨带宽度（横画 = 笔尖高、竖画 = 笔尖宽的一半），填充出真正的荧光笔形态。
  笔尖不随速度、压感变化，宽度恒定。

### 其他

- **翻页岛闲置半透明**：左右翻页岛现在和工具栏共用同一套闲置淡化设置（开关、等待时间、
  透明度都一致）。设置里改一处，三个元素一起变。
- **新手引导重写**：
  - 欢迎步三个选择：「来看看怎么使用」（强调色）/「我先上课」（本次跳过，下次还提示）/
    「我不想使用 PptInk「本次隐藏」」（取消勾选，今后不再自动提示）。
  - 文案全部重写为口语短句，去掉了套话和排比。
  - 样式简化：去掉大圆底徽标，改 22px 线性图标；卡片圆角 20、留白更足。
- **AI 环境自动配置**：新增 `AiProvisioner`。开启 AI 后若环境不可用，程序按序自愈 ——
  内置运行时补齐 NumPy → 退到系统 Python → 都缺就下载嵌入式 Python 并装 NumPy，
  直到一次真实识别通过为止。设置中心的「快速检测 AI 功能」失败时会自动触发这一流程并复检。
