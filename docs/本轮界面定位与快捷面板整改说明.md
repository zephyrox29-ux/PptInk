# PptInk v0.9.6：独占槽位布局修复

## 设计原则

本轮不采用“先显示，再检查矩形有没有相交”的避碰流程，也不把元素缩成胶囊作为布局失败的补救措施。界面元素只能进入预先定义的槽位；没有完整槽位时，操作会被拒绝并给出提示。

## 硬性槽位

- **底部固定分区**：左翻页岛、中央主工具栏、右翻页岛各有独立的水平范围和触摸命中范围；中央宽度优先保留，屏幕变窄时翻页岛只在自身内部横向滚动，不能溢出到工具栏区域。
- **分割副栏**：占据中央工具栏正上方的独立行。拖动只允许在该行水平移动，纵向位置固定；工具栏调色面板展开时，副栏同步上移，且仍保留间距。
- **唯一工作面板槽**：画笔参数、橡皮参数、插件快捷面板、计时器、点名、板中板、Lua 面板及其他普通悬浮工具共享一个面板所有权。新面板必须先取得所有权，旧面板先隐藏；不能同时显示两块普通工作面板。
- **调试 HUD 专属列**：HUD 只可在左侧专用列上下移动，高度限制在当前底栏上沿以上，内容超高时在自身滚动区内滚动；普通工作面板只能放在 HUD 列右侧。HUD 关闭时该列不再保留。屏幕过窄时不绘制无法与 HUD 并排的状态徽标。
- **诊断徽标专属带**：启用调试模式和状态徽标时，屏幕最上方保留固定高度的系统带；工作面板的整个工作区从其下方开始。打开调试模式/状态徽标前，先关闭已有工作面板并撤下旧通知。
- **通知专属带**：Toast 只占据顶部右侧通知带；调试徽标启用时通知带整体下移。工作面板或模态界面打开时不显示通知。若屏幕没有完整通知槽，就排队延后，而不是寻找任意空白矩形或覆盖现有控件。
- **模态界面互斥**：聚光灯、引导等模态状态独占舞台。引导使用明确的“镂空保留工具栏”模式；其他瞬态面板在进入模态时先退出。

## 拖动约束

工具栏拖动仅在中央底栏内生效；副栏拖动仅在其独立行内水平生效；翻页岛没有拖动手势；HUD 保持在固定左列；唯一工作面板只能在上方工作区内移动。没有获得对应槽位的普通面板不应直接显示或接受拖动。

长按工具栏手柄的胶囊形态仍保留为用户主动触发的独立功能，但布局冲突不会自动触发该功能。

## 其他修正

- 为画笔参数面板拒绝打开的路径统一清除旧测量约束，避免下一次打开时沿用过期高度。
- Toast 根据预定的 HUD 右侧通知带定位，不再逐帧扫描矩形相交情况。
- 插件仍由工具栏快捷入口唤起，设置页的插件开关只用于启用/禁用。
- AI 自检只验证桥接/合成识别流程，不修改 AI 启用状态。

## 验证边界

已执行 Python 单元/桥接回归测试以及本轮新增的源码结构契约测试。当前执行容器没有 .NET SDK/MSBuild，也没有 Windows 桌面或 PowerPoint，因此**没有声称本轮通过 WPF 编译或实际放映验收**。请在 Windows 上执行项目的 Release `dotnet publish`，再验证单屏/双屏、不同 DPI、触摸拖动与分割栏、工具参数面板、插件面板、调试 HUD 和模态状态切换。
