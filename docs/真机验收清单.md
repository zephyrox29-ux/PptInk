# PptInk v1.1.1 真机验收清单

> 使用对象：带触控大屏/投影 + Windows 课堂环境的实机测试。
> 目标版本：v1.1.1（便携包 `PptInk-v1.1.1-portable-win-x64.zip`，解压即用）。
> 用法：按顺序过一遍，每项打勾或记问题描述。**任何一项失败，先托盘「导出诊断包」，
> 连同当时现象（怎么操作的、预期是什么、实际是什么）一起反馈。**

## 0. 准备（5 分钟）

- [ ] 解压便携包到测试机，双击「启动融绘.bat」
- [ ] 确认测试机环境：教室大屏（希沃/其他）/ 笔记本 + 投影 / 纯触摸一体机，记下型号
- [ ] 准备一份 10 页以上的 PPT（含可点击对象如超链接按钮，第 3 节用）
- [ ] 准备翻页笔（若测试第 6 节）
- [ ] 托盘右键 →「导出诊断包」跑一次，确认能生成 zip（这一步同时验证了排障链路）

## 1. 启动 / 驻留 / 退出

- [ ] 启动后只有托盘图标，无窗口、无弹窗
- [ ] 再次双击启动器 → 已驻留实例被唤起（工具栏出现），不产生第二个进程
- [ ] 托盘菜单各项可见：手动唤起 / 锁定 / 引导 / 严格手掌 / 调试 / 导出板书 / **导出诊断包** / 设置 / 隐藏 / 退出
- [ ] **退出后桌面无新文件**（v1.1.1 起自动导出默认关闭——若发现桌面出现 `PptInk导出` 文件夹，是回归）
- [ ] 托盘「立即播放新手引导」→ 桌面播完/跳过后**工具栏自动收回**（旧版滞留桌面无法退出）
- [ ] 设置中心：**按住标题栏可拖动窗口**（原生移动，无闪动）；材质选项为
      实体色/半透明/极简融合三种（亚克力在分层窗口上做不了真模糊，已移除）
- [ ] 托盘「退出融绘」→ 进程消失、托盘图标消失

## 2. 未放映书写（托盘「手动唤起工具栏」）

- [ ] 工具栏 + 左右翻页岛出现在**当前主屏**底部，位置正确不越界
- [ ] 鼠标在空白处拖动能画出笔迹（颜色默认朱红）
- [ ] **工具栏缩放**：设置 → 工具栏 → 缩放调到 70% / 100% / 160%，每次调整后：
      工具栏在左右翻页岛之间、底边贴停靠线不悬空、按钮不压翻页岛（v1.1.1 重点修复项）
- [ ] 160% 下点开画笔/荧光笔的调色面板：面板向上展开，不盖住副岛行、不出屏
- [ ] 长按工具栏手柄 600ms → 收成胶囊；点胶囊展开恢复
- [ ] 工具栏完整：触摸/笔/荧光笔/擦除/撤销/重做/AI/插件/结束放映全部可见（旧版「只剩
      基础工具」的分割黑洞已移除，若再出现即为回归）
- [ ] **自由拖动**：拖手柄可上下左右任意移动工具栏（不再锁死横轴），位置重启后保留
- [ ] **插件按钮**：点击弹出组件面板（计时器/聚光灯/点名/截图）；若无效，先播一次
      新手引导再试（旧版引导租约不释放会静默锁死全部面板，已修复）
- [ ] 拖动工具栏手柄：只能左右移动，松手停留在中央槽内
- [ ] 撤销/重做、三种擦除（涂抹/圈画/滑动清空）、颜色粗细调整正常
- [ ] **聚光灯**：插件快捷面板 → 聚光灯：暗罩出现（v1.1.1 修复，旧版只有圆环），
      拖圆环暗区跟随，点暗区退出

## 3. 放映进入与屏幕定位（重点，对应「浮窗乱跑」）

单屏环境：
- [ ] 开始放映 → 工具栏**第一帧就在本屏**出现，没有「先出现在别处再跳过来」
- [ ] 放映中按 Esc 退出 → 工具栏收回；再从托盘打开设置 → 设置窗出现在**本屏中央**

双屏 / 投影环境（笔记本 + 大屏）：
- [ ] 在大屏放映 → 墨迹层与工具栏全部盖在**大屏**上，笔记本屏无残留
- [ ] 笔记本屏 100% + 大屏 100%：上述正常
- [ ] **混合缩放**（笔记本 125%/150% + 大屏 100%，或反之）：工具栏完整覆盖放映屏、
      位置尺寸正确（v1.1.1 核心修复，开发机只能验单屏，此项必须真机确认）
- [ ] 放映中把放映窗口挪到另一块屏（PPT 设置里选监视器）：整套 UI 跟随过去，
      擦除浮岛/插件面板收回、再次点击重新弹出（不再滞留旧屏边缘）
- [ ] 拔掉大屏线再插回：UI 能回到正确位置（允许一次自动跳变，不应反复跳屏）
- [ ] 放映中改显示缩放：UI 尺寸跟随，0.5 秒左右稳定下来

## 4. 触控与笔（真机核心）

- [ ] 手指书写：落笔即出墨，无明显延迟；连续快速书写不丢笔、不断线
- [ ] 手掌搭屏（如平时板书姿势）：不落墨；手掌移开后手指立刻恢复书写
- [ ] 手掌抑制误杀：正常书写指尖不被判成手掌（观察调试 HUD 绿/红矩形）
- [ ] 有源/无源笔书写：压感变化可见（线宽随力度变化）；笔的橡皮头能擦除（若支持）
- [ ] 三档输入模式（设置 → 输入模式）切换后书写正常；「触摸操作」档下点 PPT 上的
      超链接/按钮能点到（板书隐藏、点击穿透）
- [ ] **墨点可擦除**：轻点屏幕留下一枚墨点 → 换擦除拖过它 → 墨点消散（旧版单点笔迹
      永远擦不掉，已修复）
- [ ] 书写中翻页：笔迹跟随页面切换，不出现半笔拖到新页
- [ ] 擦除流畅度：荧光笔大面积涂写后连续擦除不卡顿（卡顿则记录机型与场景）

## 5. PowerPoint 放映集成

- [ ] PowerPoint（记版本，如 2016/365）：开始放映自动唤起；页码岛显示「当前/总页」
- [ ] 翻页岛按钮：下一页/上一页有效；键盘方向键在 PPT 聚焦时正常翻页
- [ ] **快捷跳页**：点按翻页岛的页码胶囊 → 弹出页码网格 → 点选页码即跳转
      （COM 直跳；开发机已实测。WPS 兜底通道下提示需要放映支持）
- [ ] **翻页笔**：焦点在 PptInk（刚点过工具栏）时按翻页笔 → PPT 翻页；
      设置窗输入框里按方向键 → 光标移动、不翻页（v1.1.1 扩充修复）
- [ ] 退出放映 → 工具栏收回、进程回驻留
- [ ] 同一课件停止后再放映：批注保留
- [ ] **换一份课件放映**：旧批注清空 + 提示「已切换课件：旧板书已清空…」；
      开启「退出时自动导出」后重复此步：桌面 `PptInk导出` 出现旧板书存档
- [ ] PPT 假死（任务管理器挂起 PPT 数秒再恢复）：UI 不冻结，能自愈

## 6. WPS 演示（若测试机装有）

- [ ] WPS 放映能被检测（页码岛有数；若 `– / –` 但书写正常，记为「兜底通道模式」）
- [ ] 翻页按钮/翻页笔在 WPS 下的表现（COM 不可用则走推算，页码可能与实际差 1，
      记录现象即可）

## 7. AI 形状识别

- [ ] 设置 → AI：点「快速检测」；缺运行时时应**先弹窗询问是否联网下载**
      （说明 python.org/PyPI 来源与体积），选「取消」→ 不下载、AI 不启用、书写不受影响
- [ ] 同意下载 → 完成后自检通过（首次可能需几分钟）；重复检测秒过
- [ ] 识别效果：画圆 → 停笔弹「规整为圆」气泡/自动替换；1080p 与 4K 屏各试一次，
      **气泡应出现在笔迹上方**而不是屏幕右侧（v1.1.1 修复）
- [ ] 撤销能恢复原始笔迹；「最近几笔」模式画圆+箭头组合能整体替换不重影
- [ ] AI 全程不联网推理（可拔网线验证一次识别仍可用）

## 8. 稳定性与取证

- [ ] 完整模拟一节课（30 分钟书写 + 每分钟翻页）：无卡死、无崩溃、内存不明显爬升
- [ ] 任何异常后：托盘「导出诊断包」，确认 zip 里有 environment.txt / config.json / logs
- [ ] 日志抽查（配置文件夹 logs）：有「放映开始/结束」「翻页」「放映屏变化」条目，
      便于回溯（v1.1.1 新增）

## 已知限制（不是缺陷，不用报）

- 触控手感、穿透行为依赖设备驱动，个别整机需要换输入档位（设置 → 输入模式）
- WPS 旧版本 COM 事件不可用时页码走推算，可能偏差 1 页
- 4K 大屏大量笔迹下的擦除性能待优化（本版本未动渲染缓存架构）
- 混合 DPI 定位修复在开发机上只能验单屏路径，本清单 3-混合缩放是首次真机验证点
