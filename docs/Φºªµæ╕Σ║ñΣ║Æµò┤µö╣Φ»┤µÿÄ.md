# PptInk v0.9.6 触摸交互整改说明

## 本轮目标

围绕触摸大屏的一体化界面输入，修正拖动、绘制、翻页和调色面板之间的输入所有权冲突；统一为按下即响应、滑动只驱动当前手势、抬起释放，不依赖鼠标悬停状态。

## 已修改内容

### 1. 工具栏手柄与绘制输入隔离

- 手柄改为独立的 `Border` 拖动命中区，不再复用按钮点击状态机。
- 鼠标、触摸、手写笔在 Down 阶段明确选定输入源并捕获设备，保证触点离开手柄边界后 Move/Up 仍回到原手势。
- 拖动位置统一按“按下时工具栏位置 + 当前指针相对按下点的位移”计算，避免元素移动后局部坐标变化、重复累加位移导致的跳动。
- 长按收纳、正常松手、设备丢失捕获分别清理会话；释放前先清除捕获引用，避免 LostCapture 回调递归。
- 画布墨迹层维护 UI 命中矩形快照。触点若从工具栏、翻页岛、插件、引导或 HUD 区域开始，整次接触都不会转成绘制笔迹；即使随后滑出控件区域也不会突然落墨。

### 2. 按钮统一为触摸优先

- 移除公共按钮处理器的固定 350ms 时间去重，快速的独立连续点击不再被时间窗吞掉。
- 公共按钮、设置页主题/强调色/材质卡、分段选项、通用开关、插件按钮、引导按钮及形状辅助按钮统一使用按下事件，按下即执行操作。
- 输入会话记录设备类型并捕获设备；松开立即释放，丢失捕获可恢复，不再因旧手势残留而长期锁住控件。
- 删除交互模板中的 `IsMouseOver` 视觉依赖；保留按压反馈，不要求用户先悬停或经过悬停状态。

### 3. 左右翻页岛固定呈现

- 左右两个翻页岛始终创建、始终参与界面显示，分别固定在放映屏左下角与右下角。
- 移除翻页岛拖动/保存位置的处理；两侧不再因旧配置而隐藏。
- 启动时将旧版左右岛开关配置迁移为开启；两个翻页岛均取消闲置淡化，避免看起来像只剩一个。
- 上一页、下一页都沿用公共按下即响应的触摸按钮。

### 4. 画笔面板重整

- 面板作为主工具栏同一 WPF 视觉树中的元素渲染，不另建窗口；重复点选当前画笔/荧光笔可展开或收回面板。
- 展开位置以当前工具按钮为锚，依据工具栏上、下可用空间选择方向，并做屏幕左右边界钳制。
- 先填充最近颜色，再测量真实内容；面板尺寸参照工具栏宽度，同时限制内容视口高度并允许触摸滚动，避免因折叠测量或内容过高而裁切。
- 常用色圆点置于视觉上独立的胶囊区域中，但仍留在同一控件树内；颜色、笔宽和 RGB 调整使用足够大的触摸命中区。
- 面板关闭分为常规收回动画与拖动/切换界面时的立即收回，避免面板残留、工具栏位置偏移或动画互相争抢。

### 5. 通用拖动与聚光灯

- `DragKit` 补足鼠标、触摸、手写笔捕获与捕获丢失后的会话清理。
- 插件聚光灯的圆形定位区可通过触摸/笔/鼠标拖动，且捕获丢失可恢复；点击暗区可关闭，不依赖鼠标专属事件。
